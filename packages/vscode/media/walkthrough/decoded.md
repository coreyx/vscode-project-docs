# Read coded docs with real values

A coded doc uses placeholders such as `myhost`. To read it with the real values from PRIVATE.md, click the **eye** in the doc's title bar.

The decoded view:

- opens beside the coded file, with a tab ending **(Decoded: real values shown)**;
- shows **Decoded: real values shown** in the status bar, and **Coded** when you're back on the coded file;
- follows your edits to the coded file and to PRIVATE.md;
- **can't be edited or saved**, so real values can't end up in a file by accident.

Click the closed eye to go back to the coded file. **Open Decoded Preview** shows the same text in VS Code's Markdown preview.

If PRIVATE.md is missing or invalid, nothing is decoded, and you see why.
